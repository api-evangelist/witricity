# WiTricity (WiTricity AI Tech, LLC)

> WiTricity commercializes highly resonant magnetic-resonance wireless power
> transfer — the technology published by an MIT team led by Marin Soljacic in
> 2007 — by licensing its foundational patent portfolio, reference designs and
> engineering services to automakers, Tier 1 suppliers and charging hardware
> makers. It is a hardware and intellectual-property company, not a software
> vendor: as of 2026-09-04 it publishes no developer program, no API
> documentation, and no machine-readable API contract.

## API surface

No public API. Probed 2026-09-04: `api.`, `developer.`, `docs.`, `dev.` and
`portal.witricity.com` all return NXDOMAIN; `/openapi.json`, `/openapi.yaml`,
`/swagger.json`, `/api-docs`, `/llms.txt`, `/apis.json`, `/.well-known/apis.json`,
`/.well-known/agent-card.json` and the full named `/.well-known/` discovery list
each return HTTP 404 on both `witricity.com` and `www.witricity.com`. No GitHub
organization exists at github.com/witricity (HTTP 404), and no first-party client
library is published on npm, PyPI, RubyGems or crates.io. Integration with
WiTricity systems is delivered through licensee engineering support and custom
development, described at the Engineering Services page below.

## Standards

- [Standards](https://www.witricity.com/standards.php): WiTricity chairs several SAE J2954 working groups — the SAE interoperability standard for wireless charging of EVs and PHEVs — and participates in related standards bodies. J2954 is a hardware interoperability standard, not an API specification.
